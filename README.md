# 📘 Aplikasi Tugas Kuliah (Kelompok 1)

Aplikasi sederhana berbasis **Android Studio (Java)** yang dibuat untuk membantu mahasiswa dalam **mengelola jadwal dan tugas perkuliahan**.  
Tujuan aplikasi ini adalah agar mahasiswa dapat lebih terorganisir dan tidak lupa dengan tugas atau kegiatan penting selama perkuliahan.

---

## 🚀 Fitur Utama

- ✅ **Tambah Tugas / Jadwal Kuliah**  
  Mahasiswa dapat menambahkan nama mata kuliah, deskripsi tugas, tanggal, dan jam pengumpulan.

- 🕒 **Pengingat Deadline Tugas**  
  Menampilkan tanggal dan jam tugas, serta memberi notifikasi jika waktu pengumpulan sudah dekat.

- ✏️ **Edit & Hapus Data Tugas**  
  Memungkinkan pengguna untuk memperbarui atau menghapus tugas yang sudah dibuat.

- 📅 **Tampilan Daftar Tugas**  
  Semua tugas tampil dalam daftar yang rapi agar mudah dilihat dan diatur.

---

## ⚖️ Perbandingan dengan Google Classroom

| Fitur                            | Google Classroom | Aplikasi Tugas Kuliah |
|----------------------------------|------------------|------------------------|
| Pengingat tugas otomatis         | ✅ Ada            | ✅ Ada (manual input)  |
| Upload file / tugas              | ✅ Ada            | ❌ Tidak tersedia      |
| Tampilan sederhana & offline     | ❌ Tidak          | ✅ Ya (tanpa internet) |
| Cocok untuk tugas pribadi        | ❌ Kurang cocok   | ✅ Sangat cocok        |

> Aplikasi ini tidak dimaksudkan untuk menggantikan Google Classroom,  
> melainkan sebagai **alat bantu pribadi mahasiswa** untuk mencatat tugas dan pengingat harian.
